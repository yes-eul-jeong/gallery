# 서비스 기획

작성일: 2026-09-22

## 1. 무엇을 만드는가

프로 킥복싱 선수가 **프로모터에게 보내는 파이트 레주메**다.

경기 제안을 받거나 스스로 제안할 때, 링크 하나로 전적과 실력을 증명하는 것이 목적이다.
사진과 영상을 모아 보여주는 갤러리가 아니라 판단 자료다. 영상은 전적이 사실임을 뒷받침하는
근거로 존재한다.

이 구분이 화면 설계를 결정한다. 감상용 그리드가 아니라 스캔용 목록이 기본이 된다.

## 2. 보는 사람

### 2.1 김성호 · 국내 단체 매치메이커 · 38세 (주 대상)

3월 대회 카드 12경기 중 4자리가 비어 있다. -63kg 자리에 넣을 선수를 찾다가 체육관 관장에게
링크를 받았다. 지하철에서 휴대폰으로 연다.

첫 화면에서 30초 안에 거를지 남길지 정한다. 남기면 저장해뒀다가 사무실 데스크톱에서 풀 경기를 본다.
두 경기 정도 확인하고 결정하면 그날 안에 연락한다.

- 이탈 지점: 전적이 안 보인다, 영상이 안 돌아간다, 하이라이트만 있다, 최근 경기가 2년 전이다
- 필요한 것: 스크롤 없이 스펙 확인, 풀 경기 즉시 재생, 연락 수단

### 2.2 타나카 히로시 · 일본 단체 매치메이커 · 45세 (2차)

외국인 선수를 섭외한다. 한국어를 못 읽는다. 체급과 전적은 숫자라 알아보지만 대회명과 상대 이름이
한글이면 검증할 수 없다.

지금 단계에서는 대응하지 않는다. 다국어는 후순위 과제로 남긴다.

### 2.3 박지원 · 스포츠 브랜드 마케팅 · 31세 (부차)

용품 후원 대상을 고른다. 실력보다 노출 가치를 본다. SNS 팔로워, 경기 빈도, 사진 품질을 본다.

### 매치메이커의 확인 순서

| 순서 | 확인 | 이유 |
|---|---|---|
| 1 | 체급 | 계체를 통과하나. 못 맞추면 그 자리에서 탈락 |
| 2 | 전적 | 상대 선수와 수준이 맞나 |
| 3 | 랭킹 · 타이틀 | 카드의 격을 올릴 수 있나 |
| 4 | 최근 경기 영상 | 전적대로 싸우나 |
| 5 | 가용 시기 | 그 날짜에 뛸 수 있나 |
| 6 | 연락처 | 되겠다 싶으면 바로 연락 |

하이라이트 영상은 신뢰받지 못한다. 좋은 장면만 편집한 것이라 실력을 판단할 수 없기 때문이다.
풀 경기를 올린다. 패배 경기도 올린다. 어떻게 이기는지보다 어떻게 지는지가 매치업 판단에 쓸모 있고,
승리만 있는 전적표는 오히려 의심을 부른다.

## 3. 콘텐츠

### 3.1 경기

| 항목 | 필수 | 예시 |
|---|---|---|
| 날짜 | O | 2025-05-12 |
| 대회명 | O | MAX FC 30 |
| 룰 | O | K-1 / 무에타이 / 오리엔탈 |
| 체급 | O | -63kg |
| 상대 선수 | O | 홍길동 |
| 상대 소속 | | ○○짐 |
| 라운드 형식 | O | 3R 3분 |
| 결과 | O | 승 / 패 / 무 / 무효 |
| 결정 방식 | O | KO / TKO / 판정(만장일치) / 판정(다수) / 판정(스플릿) / 기권 |
| 결정 시점 | | 2R 1:34 |
| 구분 | O | 프로 / 아마추어 |
| 타이틀전 | | 타이틀명, 도전 / 방어 |
| 제목 | O | 카드에 표시할 한 줄 |
| 설명 | | 경기 내용 |

룰을 별도로 받는 이유는 킥복싱이 단체마다 규칙이 다르기 때문이다. 팔꿈치와 클린치 허용 여부가
달라 무에타이 룰 경기와 K-1 룰 경기는 보는 쪽에서 다른 경기로 취급한다.

타이틀전은 목록에서 따로 표시한다. 매치메이커에게 타이틀전 경험은 별도 지표다.

프로 전적과 아마추어 전적은 합산하지 않는다. 격투기에서 두 기록을 섞어 적는 것은 결례로 본다.

### 3.2 훈련 영상

| 항목 | 필수 | 예시 |
|---|---|---|
| 날짜 | O | 2025-03-02 |
| 유형 | O | 스파링 / 미트 / 샌드백 / 기술 / 체력 |
| 제목 | O | 로우킥 카운터 |
| 설명 | | 자유 입력 |

### 3.3 사진

경기 사진, 계체, 시상, 훈련 스냅. 경기나 훈련 항목에 묶어 등록하면 해당 상세에서 함께 보인다.

### 3.4 프로필

| 구분 | 항목 |
|---|---|
| 기본 | 이름, 영문 이름, 생년, 소속 체육관 |
| 신체 | 신장, 체급 |
| 실적 | 프로 전적, 아마추어 전적, 랭킹, 보유 타이틀 |
| 활동 | 출전 가능 시기 |
| 연락 | 인스타그램 계정 |

랭킹은 단체명, 체급, 순위, 기준 날짜를 함께 기록한다. 순위만 적으면 어느 단체 기준인지 알 수 없고,
날짜가 없으면 언제 기준인지 검증할 수 없다.

```
대한킥복싱협회 -63kg 3위 (2025.12 기준)
```

## 4. 전적 자동 집계

경기 항목의 결과 값에서 전적을 계산한다. 따로 관리하는 숫자가 없으므로 전적과 경기 목록이 어긋날 수 없다.

```
프로  12승 3패  ·  KO 5
아마  3승 1패
```

- `구분: 프로` 인 항목만 프로 전적에 반영한다
- KO 수는 결정 방식이 KO 또는 TKO 인 승리를 센다
- 무효 경기는 전적 수에서 제외한다

## 5. 화면

### 5.1 첫 화면

휴대폰 한 화면 안에서 판단이 끝나야 한다. 스크롤을 요구하는 순간 이탈한다.

```
┌─────────────────────────────────────────┐
│  홍길동                                  │
│  ○○짐 · 1998년생                        │
│                                          │
│       12 - 3          KO 5              │
│                                          │
│  -63kg  ·  173cm                        │
│  대한킥복싱협회 -63kg 3위                │
│                                          │
│  ▸ 2026년 3월 이후 출전 가능             │
│                                          │
│  ┌───────────────────────────────────┐  │
│  │  @instagram_id                    │  │  ← 하단 고정
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

전적 숫자를 페이지에서 가장 크게 다룬다. 첫 화면이 하는 일은 그것 하나다.

타이틀을 보유하게 되면 전적 위에 벨트 표기가 들어간다. 타이틀전이 잡히면 예정 경기를 같은 자리에 올린다.

### 5.2 경기 목록

전적표 형식이다. 카드 그리드가 아니다. 매치메이커는 감상하지 않고 훑는다.

```
┌─ 경기 ─────────────────────────────────┐
│ 2025.05.12   MAX FC 30                 │
│ vs 홍길동 (○○짐)      K-1룰 3R        │
│ ● 승 · KO 2R 1:34             [ 영상 ] │
├────────────────────────────────────────┤
│ 2025.02.08   KING OF KINGS  🏆타이틀전 │
│ vs 김철수 (△△짐)     무에타이룰 5R    │
│ ○ 패 · 판정(스플릿)           [ 영상 ] │
└────────────────────────────────────────┘
          전체 전적 보기 (15경기) ▾
```

최근 5경기를 펼치고 나머지는 접는다. 15경기를 전부 늘어놓으면 최근 경기가 묻힌다.

승패는 색으로 구분하되 채도를 낮춘다. 빨강과 초록을 그대로 쓰면 값싸 보인다.

### 5.3 영상 재생

목록에서 영상 버튼을 누르면 전체 화면 재생기가 열린다.

- 재생, 일시정지, 구간 이동, 배속, 전체화면, 음량
- ESC로 닫기
- 하단에 경기 정보 표시
- 주소가 남아 링크로 직접 공유할 수 있다

배속은 실제로 쓰인다. 5라운드 경기를 전부 볼 시간이 없는 사람이 1.5배로 훑는다.

### 5.4 훈련 · 사진

경기 목록 아래에 둔다. 여기는 카드 그리드가 맞다. 판단 자료가 아니라 보조 자료이기 때문이다.

유형 필터를 두고, 카드를 누르면 재생기나 사진 뷰어가 열린다. 사진은 좌우 키로 넘긴다.

### 5.5 대회별 보기

대회 단위로 묶어 보는 화면. 특정 경기를 찾는 사람을 위한 경로다.

## 6. 미디어 보호

원본 다운로드와 무단 재배포를 억제한다. 브라우저 재생 구조상 완전 차단은 불가능하므로 목표를 셋으로 한정한다.

1. 고정 다운로드 주소가 존재하지 않을 것
2. 다른 사이트에 직접 삽입할 수 없을 것
3. 유출되더라도 출처가 남을 것

구현 수단은 개발 문서에 정리한다.

## 7. 디자인 방향

- 어두운 배경. 경기 사진과 영상이 화면에서 살아나게 한다
- 전적 숫자가 페이지에서 가장 큰 요소다
- 텍스트 장식을 줄인다. 이 사이트는 읽히는 것이 아니라 확인되는 것이다
- 승패 색은 채도를 낮춘다
- 모바일 우선. 링크를 받은 사람 대부분이 휴대폰으로 연다
- 로딩이 느리면 이탈한다. 첫 화면에 무거운 요소를 넣지 않는다

색상과 타이포그래피는 화면을 만든 뒤 시안으로 결정한다.

## 8. 우선순위

영상 업로드와 재생이 선결 과제다. 이것이 동작하지 않으면 나머지 화면은 의미가 없다.

| 단계 | 내용 | 검증 기준 |
|---|---|---|
| 1 | 영상 한 편을 인코딩해 올리고 재생 | 휴대폰에서 끊김 없이 재생되고, 직접 주소로는 접근되지 않는다 |
| 2 | 첫 화면과 경기 목록 | 전적이 자동으로 계산되어 표시된다 |
| 3 | 업로드 CLI 완성 | 명령 한 줄로 등록부터 배포까지 끝난다 |
| 4 | 훈련 · 사진 · 대회별 보기 | |
| 5 | 디자인 마감 | |
