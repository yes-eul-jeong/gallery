# 서비스 기획

작성일: 2026-09-22

## 1. 목적

프로 킥복싱 선수의 경기와 훈련 기록을 한곳에 모아, 링크 하나로 전달할 수 있는 포트폴리오를 만든다.

기존 방식의 한계를 해소하는 것이 목표다. 영상이 인스타그램, 유튜브, 개인 휴대폰에 흩어져 있으면
상대에게 보여줄 때마다 골라서 보내야 하고, 전적과 경기 영상이 따로 놀아 신뢰를 주기 어렵다.

## 2. 보는 사람

| 대상 | 확인하려는 것 |
|---|---|
| 프로모터 · 매치메이커 | 전적, 체급, 최근 경기력, 경기 스타일 |
| 체육관 · 소속팀 | 기술 수준, 훈련 태도, 성장 추이 |
| 스폰서 | 활동 빈도, 노출 가치, 이미지 |
| 팬 | 경기 하이라이트 |

방문자 수는 적다. 월 수 명 수준을 전제로 하되, 언제 들어올지 모르는 사람이 보는 사이트이므로
가용성은 상시 유지한다.

## 3. 콘텐츠

### 3.1 경기 영상

프로 경기를 기본 단위로 한다. 패배 경기도 내용이 좋으면 게시한다.

| 항목 | 필수 | 예시 |
|---|---|---|
| 날짜 | O | 2025-05-12 |
| 대회명 | O | MAX FC 30 |
| 룰 | O | K-1 / 무에타이 / 오리엔탈 |
| 체급 | O | -63kg |
| 상대 선수 | O | 홍길동 |
| 상대 소속 | | ○○짐 |
| 라운드 형식 | O | 3R 3분 |
| 결과 | O | 승 / 패 / 무 / 무효 |
| 결정 방식 | O | KO / TKO / 판정(만장일치) / 판정(다수) / 판정(스플릿) / 기권 |
| 결정 시점 | | 2R 1:34 |
| 구분 | O | 프로 / 아마추어 |
| 제목 | O | 카드에 표시할 한 줄 |
| 설명 | | 경기 내용, 소감 |

룰을 별도로 받는 이유는 킥복싱이 단체마다 규칙이 다르기 때문이다. 팔꿈치와 클린치 허용 여부가
달라 무에타이 룰 경기와 K-1 룰 경기는 보는 쪽에서 다른 경기로 취급한다.

프로 전적과 아마추어 전적은 합산하지 않는다. 격투기에서 두 기록을 섞어 적는 것은 결례로 본다.

### 3.2 훈련 영상

| 항목 | 필수 | 예시 |
|---|---|---|
| 날짜 | O | 2025-03-02 |
| 유형 | O | 스파링 / 미트 / 샌드백 / 기술 / 체력 |
| 제목 | O | 로우킥 카운터 |
| 설명 | | 자유 입력 |

### 3.3 사진

경기 사진, 계체 사진, 시상, 훈련 스냅을 포함한다. 경기나 훈련 항목에 묶어서 등록하면
해당 상세 화면에서 함께 보인다. 묶지 않은 사진은 전체 갤러리에만 나타난다.

### 3.4 프로필

이름, 생년, 신장, 체중, 체급, 소속 체육관, 프로 전향 시기, 파이팅 스타일, SNS 링크.

## 4. 전적 자동 집계

경기 항목의 결과 값을 모아 전적을 계산한다. 별도로 관리하는 숫자가 없으므로 전적과 경기 목록이
어긋날 수 없다.

```
프로  12전 9승 3패  ·  KO 5
아마  4전 3승 1패
```

집계 규칙은 다음과 같다.

- `구분: 프로` 인 항목만 프로 전적에 반영한다
- KO 수는 결정 방식이 KO 또는 TKO 인 승리를 센다
- 무효 경기는 전적 수에서 제외한다

## 5. 화면 구성

### 5.1 메인

```
┌──────────────────────────────────────┐
│  이름 · 체급 · 소속                   │
│  프로 12전 9승 3패 · KO 5             │
│  173cm / 63kg                        │
├──────────────────────────────────────┤
│  [ 경기 ]  [ 훈련 ]  [ 사진 ]         │
├──────────────────────────────────────┤
│  2025 ─────────────────────────────  │
│  ┌────────┐ ┌────────┐ ┌────────┐   │
│  │ 썸네일 │ │ 썸네일 │ │ 썸네일 │   │
│  │ MAX30  │ │ MAX28  │ │ 훈련   │   │
│  │ 승 KO  │ │ 판정승 │ │ 스파링 │   │
│  └────────┘ └────────┘ └────────┘   │
│  2024 ─────────────────────────────  │
│  ...                                 │
└──────────────────────────────────────┘
```

상단에 프로필과 전적을 고정 노출한다. 그 아래 카드 그리드가 최신순으로 깔리고,
연도가 바뀌는 지점에 구분선이 들어간다.

경기 카드에는 대회명, 상대, 결과를 함께 표시한다. 썸네일만으로는 어떤 경기인지 알 수 없다.

### 5.2 필터와 정렬

- 구분: 전체 / 경기 / 훈련 / 사진
- 정렬: 최신순 / 오래된순
- 대회별 보기: 대회 단위로 묶어서 표시
- 룰: K-1 / 무에타이 / 오리엔탈
- 훈련 유형: 스파링 / 미트 / 샌드백 / 기술 / 체력

필터 상태는 URL 쿼리에 반영해 링크로 공유할 수 있게 한다.

### 5.3 상세

카드를 누르면 전체 화면 뷰어가 열린다.

- 영상: 재생, 일시정지, 구간 이동, 배속, 전체화면, 음량
- 사진: 확대, 이동, 좌우 넘김
- 좌우 방향키로 같은 묶음 안을 이동
- ESC로 닫기
- 하단에 경기 정보 표시

주소창에 상세 경로가 남아 링크로 직접 공유할 수 있다.

### 5.4 대회별 보기

대회 단위로 구획이 나뉘고 그 안에 해당 경기 영상과 사진이 모인다. 특정 경기를 찾는 사람을 위한 화면이다.

## 6. 미디어 보호

원본 다운로드와 무단 재배포를 억제한다. 완전한 차단은 브라우저 재생 구조상 불가능하므로,
목표를 다음 세 가지로 한정한다.

1. 고정 다운로드 주소가 존재하지 않을 것
2. 다른 사이트에 직접 삽입할 수 없을 것
3. 유출되더라도 출처가 남을 것

구현 수단은 개발 문서에 정리한다.

## 7. 디자인 방향

격투기 포트폴리오의 성격에 맞춰 다음을 기준으로 잡는다.

- 어두운 배경. 영상 썸네일과 경기 사진이 화면에서 튀어나오게 한다
- 텍스트 장식을 줄이고 미디어를 크게 쓴다
- 전적 숫자는 페이지에서 가장 큰 글자로 다룬다
- 승패 표기는 색으로 구분하되 채도를 낮춘다. 빨강과 초록을 그대로 쓰면 촌스러워진다
- 모바일 우선. 링크를 받은 사람 대부분이 휴대폰으로 연다

구체적인 색상과 타이포그래피는 구현 단계에서 시안을 만들어 결정한다.
